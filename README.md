# Turop

Hazme una aplicación (que funciones tanto para el computador como para el celular(basicamente ten en cuenta el tamaño y dimensiones))en el que pueda conectar varias cuentas(que le ponga la informacion de la cuenta para incluirla(como correo,plan, contraseña, etc.)) de entretenimiento(como nexflix, disney plus, prime video, etc.), que cuando ya puso una cuenta, le aparezaca un items con un "+" para que si el usuario tiene mas cuentas pueda ingresarlas, y al estar vinculadas se pueda pagar desde allí los servicios de esas cuentas(dependiendo el plan que tenga cada cuenta, si es un año, o por mes), para no tener que ir a cada cuentas y pagar por separado, sin que todo en conjunto, y que muestre notificaciones en la barra de notificaciones recordando cada que falte una semana para que se venza el plan que tiene el cliente. Vas a usar la paleta de colores llamada "Neutral Harmony Bliss" de Coolors.
